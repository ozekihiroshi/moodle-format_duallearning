# Security policy

Please report suspected security vulnerabilities privately through GitHub Security Advisories:

https://github.com/ozekihiroshi/moodle-format_duallearning/security/advisories/new

Do not include sensitive learner, teacher, or site data in a public issue. For ordinary bugs and feature requests, use the public issue tracker:

https://github.com/ozekihiroshi/moodle-format_duallearning/issues
