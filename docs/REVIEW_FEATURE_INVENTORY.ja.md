# 復習・再開機能の棚卸し

2026-09-18。対象：`format_duallearning` 0.1.0-alpha1、調査開始時HEAD `a36f2ec`。本書はソース確認と過去記録の整理であり、今回の実画面試験の合格記録ではない。

要求の正本：[学習設計仕様](LEARNING_DESIGN_SPEC.ja.md)。改修案：[一単元の作成支援詳細設計](AUTHORING_DESIGN.ja.md)。

## 1. 残すもの、補うもの

**復習のために方式を変更しない。既存教材・提出・講評へ戻る経路を残し、作成者が復習先と使い方を整える支援を加える。**

| 項目 | 現行の実装・責任主体 | 限界と改修時の扱い |
| --- | --- | --- |
| 完了済み教材の再閲覧 | 標準Topicsの活動一覧を継承。概要が完了済み教材を削除する処理はない | 権限・公開期間・利用制限は標準Moodleに従う。復習用の一覧・指定先は未実装 |
| 次の活動 | 利用可能かつ完了追跡対象の、コース順で最初の未完了活動 | 最後に見たページ・編集位置ではない。途中再開と呼ぶ際にも説明を残す |
| 全活動完了後 | 追跡対象が存在し未完了がなければ、提出・講評を確認する案内を表示 | 単元合格の判定ではない。概要内に専用の復習先ボタンはない |
| 手動完了の件数 | 課題を除く手動完了活動を集計。自動完了活動は件数に含めない | 理解度でも提出率でもない。復習開始で完了を取り消さない |
| 課題への再訪 | 利用可能な課題へリンク。個人提出の状態と公開済み評点の有無を要約 | 提出物・具体的な評点・講評は標準課題画面。グループ提出詳細も標準画面へ委譲 |
| 締切 | 課題の基本締切とタイムゾーンを表示 | 個別延長等を独自に確定しない。復習可否を締切だけで決めない |
| 作業環境への再訪 | 両方式で利用可能なLTI活動をショートカットに掲載 | すべてがPython Labとは限らない。ファイル保存・位置復元は接続先の責任 |
| 質問先 | Guidedで利用可能なforum活動を掲載 | 質問用フォーラムかは識別しない。Pathには同じショートカットがない。両方式で明示指定できるよう補う |
| 予習・振り返りの説明 | 教材本文として記載可能 | 専用入力項目や確認手順はない。既存教材に含まれる説明を捨てず参照する |
| 誤答から説明へ戻る | 教材・小テスト側のフィードバックに委ねる | 誤答別の復習ルートをフォーマットが生成する実装はない |
| 作成者への支援 | コース設定で方式を選択 | 設計意図の確認、方式別手順、公開前点検は未実装 |

ソース根拠：[`format.php`](../format.php)、[`lib.php`](../lib.php)、[`overview.php`](../classes/local/overview.php) の `build` / `collect_items` / `collect_completion` / `assignment_status` / `first_incomplete`、[`overview.mustache`](../templates/overview.mustache)、[`guided.php`](../classes/local/mode/guided.php)、[`path.php`](../classes/local/mode/path.php)。概要パネルはコース全体の表示時に挿入され、個別セクション画面では挿入されない。

注意：現行の「完了」は `COMPLETE` または `COMPLETE_PASS`。不合格完了を次候補から除外する設計ではない。対象活動がゼロの場合、全完了の案内も出ない。新しい単元案内では「追跡対象なし」「全件完了」「現在アクセスできる対象なし」を区別し、コース修了と断定しない。

## 2. 過去の試作との区別

ローカル `moodle-rescue/docs/dual-learning-project-3a-design.md` と `dual-learning-user-review.md` を照合した。

- 試作には予習・原資料確認・誤りからの戻り先・振り返りを教材として配置する設計がある。すべてをフォーマット固有の機能と数えない。
- 旧記録には提出・採点・復元・Lab保存の確認結果がある。ただし当時の試作・環境の結果であり、今回の新画面の回帰試験を代替しない。
- 「提出済みでも1/5」の読み取りに迷いがあった。教材の自己確認、課題提出、評点公開、作業ファイルの続きは分ける。
- 同一学習者のLabファイル共有は維持する。別コースの提出・成績・完了が同期する意味ではない。
- 古い文書の授業後切替案は現在の正式方針に置き換える。Guidedのまま復習できるようにする。

## 3. 改修前後の保全確認票

全行、今回の実機実施は**未実施**。改修前の複製コースで基準値を取得し、改修後に同じ操作と状態を照合する。既存の学習履歴を試験のために初期化しない。

| ID | 開始状態・操作 | 保全条件 | 要求 |
| --- | --- | --- | --- |
| R01 | Guidedで教材完了後に同じ教材を開く | 同じ方式で再閲覧できる。完了状態が変わらない | LD-05/06/08 |
| R02 | Pathで全追跡対象を完了して再訪 | 教材・提出・講評の入口が残る。合格や修了と誤表示しない | LD-06/08 |
| R03 | 未完了が複数ある途中状態で再訪 | 現行の次候補はコース順。最終閲覧位置とは表示しない | LD-06 |
| R04 | 完了追跡なし／利用可能対象なし | 達成率100%を表示しない。許可された教材一覧に戻れる | LD-04/08 |
| R05 | 提出済み・未採点／評点非公開／公開済み | 状態を区別し、講評閲覧は標準権限に従う | LD-08 |
| R06 | 個別期限・グループ課題・再提出 | 基本締切や個人要約だけで可否を断定しない | LD-08 |
| R07 | 復習先を非表示・削除・他コースへ移動 | 学生に名称・本文を漏らさず、作成者に参照不備を通知 | LD-03/06 |
| R08 | 更新／履歴付き復元／履歴なし複製 | 教材・提出・評点・完了を対応するコピー方針で保全。参照は復元先に再対応 | LD-10 |
| R09 | 小テスト不合格後に解説へ戻る | 試行・評点は標準小テストが保持。復習リンクが勝手に再受験を開始しない | LD-08 |

証跡は試験ID、版、コース、ロール、操作前後の状態、期待値、実結果、証拠の保存先を記録する。現行 `tests/mode_factory_test.php` は方式生成の3試験であり、上記の網羅試験ではない。
