# 作成ガイドと通常編集

2026-10-15。実装済み・未リリース。全章シミュレーションによる使いやすさの評価は次の段階で行う。

必要な選択を前面に出す。標準機能へのアクセスを保ちながら、一度に判断することを減らす。ガイドと通常編集は同じ単元・同じ教材を扱い、コース形式の変更や教材の複製を行わない。

## 状態と作業

ガイドは確実な状態を示す。単元紹介が保存されていること、編集者から見える保存済み教材の件数、単元と教材の表示設定を使う。件数は学生の利用可否や教材の完成度を意味しない。

- 教材がない場合は「教材の追加」を主な入口にする。
- 教材がある場合は「既存教材の編集」を主な入口にし、追加とアクセス確認も選べる。
- 各教材の操作は教材名を開くと表示する。教材名と表示・利用条件の情報は折りたたんでも残す。
- 教師ありでは授業前・授業中・授業後、自律型では説明・練習・自己確認・行き詰まりへの支援を案内する。教材の種類は強制しない。
- 公開可否や十分な学習支援があるかは教師が判断する。自動公開や独自の完了段階は追加しない。

## 通常編集との往復

ガイドは任意の作業場所である。表示中の教材はその教材の「設定」から直せる。単元全体を見直すときはガイドを使い、Moodle標準操作で作業したいときは通常編集を続けられる。ガイドに戻ることを保存や編集の必須手順にしない。

2026-10-15の案内点検では、戻り方だけが明示され、直接編集と戻らずに続ける選択が説明されていなかった。既存の通常編集の説明、保存・復帰の補足、フォーム上の保存注意を英日で修正した。ボタン・遷移・権限は変えていない。初見の利用者が自力で使い分けられることの実証は別途必要である。

「通常のコース編集を開く」は同じ単元のMoodle標準編集を開く。コアのPOST・セッションキー・権限検査を使い、編集モードを有効にする。ガイドに戻っても編集モードは勝手に解除しない。

標準の単元画面には既存の「単元の作成に戻る」が表示される。作成・編集フォームも同じ単元へ戻れるが、戻るリンクは保存処理を行わない。先に保存する必要がある旨の案内を維持する。

## 検証結果と残る評価

教師ありの既存単元と、自律型の空の非公開単元で往復を確認した。自律型では標準選択からPageを保存し、ガイドの件数が0から1へ更新され、再編集で本文を保持していることを確認した。教材操作と学生ロール確認の開閉はEnterキーで操作できた。学生ロールで非公開単元が見えず、元の教師ロールと単元へ戻れることも確認した。

ローカルの統合検査で、両形態の戻り先、他コースの単元を受け付けないこと、学生への操作拒否、既存の教材・単元レコードが変化しないことを確認した。回帰用Behatシナリオを追加し、既存の折りたたみ操作のシナリオを更新した。このローカル環境にはPHPUnit/Behatランナーがなく、CI一式は未実行。PHP構文を確認した。

改善効果はまだ仮説である。標準編集より手数が増える場面、折りたたみで必要な操作を見落とす場面、長い教材名・狭い画面での読みやすさを次の全章シミュレーションで比較する。iPhone実機・支援技術による評価も未実施である。
