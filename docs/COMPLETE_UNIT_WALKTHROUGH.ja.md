# 一単元を完成させる作成操作の検証

2026-09-18。開発ブランチ codex/simple-authoring。開発者が教師役で操作した検証であり、実際の教師による使いやすさ試験ではない。

## 完成した検証教材

教師伴走型の非表示検証単元「原資料を残す理由を説明する」に、説明ページ、○×問題1問と解説、短文提出課題を配置した。単元本文に順序と各教材へのリンクを設定した。CSV操作を課さず、原資料を保存する理由を説明できることに目標を絞り、配布ファイル未用意の依存を除いた。

- 説明：元の値を残し、加工はコピーで行う理由。
- 練習：原資料を上書きしてよいという命題の正誤。繰り返し受験可能。正誤別フィードバックと共通解説を作成。
- 提出：理由と具体的方法を2〜3文でオンラインテキストへ入力。ファイル不要、期限なし、2点満点の観点を説明に明記。
- 復習：説明・練習の再利用と、提出先での教師コメントの確認を案内。

## 標準フォームで分かった判断箇所

| 箇所 | 観察 | 今回の対応 |
| --- | --- | --- |
| 小テスト保存後 | 保存した時点では問題数0。「問題を追加する」、追加メニュー、新しい問題、形式選択を経る | 「保存して表示する→問題を追加する」の案内を追加 |
| 再挑戦と解説 | 受験回数は「評点」、解説の公開時期は「レビューオプション」。問題の解説は別画面 | 入口に設定場所と誤答プレビューを案内 |
| 課題の初期値 | この環境ではファイル提出と期限が有効。短文提出・期限なしには変更が必要 | オンラインテキスト／ファイル提出、「利用」「評点」の場所を案内。既定値を自動変更しない |
| 説明の二つの欄 | 課題には説明と活動インストラクションがある | この教材では説明に集約し、同じ文章を二重入力しなかった |
| 活動作成後の戻り先 | 標準活動画面から作成支援へ直接は戻れず、コース経由になる | 今回は既存案内を維持。入口の再発見と既存活動の再編集は改善候補 |
| 小テストの公開表示 | 問題編集画面は「この小テストは公開されています」と表示するが、単元・活動は非表示 | コース・単元・活動の非表示を読み取り確認。小テスト内部の表示だけで学生公開済みとは判断しない |

新しい設定項目や必須チェックリストは追加していない。日英の短い案内を修正した。

## 確認結果と限界

- 教師画面で問題と提出先を作成し保存。教師の小テストプレビューで意図的に誤答し、誤答の理由・共通解説・正解が送信後に表示されることを確認。
- Moodleの保存値を読み取り確認：コース・単元・3活動すべて非表示、問題1問、受験回数無制限、課題の締切・遮断日時なし、最大評点2、オンラインテキスト有効・ファイル提出無効。
- 単元本文から3活動へリンクがあることを確認。予習・復習と困ったときの具体的な行動を維持。
- 学生本人による提出、教師採点・返却の再試験は今回は行っていない。非表示の教師用検証教材であり、学生向けに公開してはいない。
- 標準フォームを開いた後の複雑さや画面数は減っていない。案内追加による時間短縮・迷いの減少は未測定。Topicsとの比較も未実施。

## 次の判断

実際の教材作成者がこの入口を使って同様の一単元を作るとき、どの説明を読んだか、設定箇所を探したか、活動追加後に戻れたかを観察する。次の実装候補は既存教材の再編集や作成支援への戻り道であり、確認項目や独自の採点設定を増やすことではない。
