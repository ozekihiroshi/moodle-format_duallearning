# 単元の活動追加入口：実装・確認記録

2026-09-18。作成支援の第2段階。対象は開発ブランチ `codex/simple-authoring`。

## 変更

- 下書き作成後、同じ単元の「単元づくりを続ける」画面へ進む。
- コース編集画面から既存単元を選んで作業を再開できる。一般セクションは一覧から除外する。
- 「説明を加える」「練習問題を作る」「提出を受ける」から、標準のページ・小テスト・課題フォームへ進む。
- 選択だけでは活動を作らない。保存・採点・完了条件・問題作成はMoodle標準機能が担当する。
- 単元の非表示状態を明示し、追加可能な活動だけを権限と有効状態に従って表示する。
- 日英の案内を用意し、予習・復習を含む既存の本文ひな型を保持する。

## 確認できた範囲

- 教師伴走型の非表示検証単元から説明ページを実際に作成・保存し、対象単元への配置と非表示の継承を画面で確認。
- 同じ単元から小テストと課題の標準作成フォームを開き、取消で戻ることを確認。問題作成・採点・提出の再試験はこの変更の確認には含まない。
- 英語の自学自習型で下書きを新規作成し、保存直後に対象単元の追加入口へ遷移することを確認。
- 自動テストは計10件・26 assertions。追加した4件はURLと単元ID、読取時の無変更、別コースの単元拒否、無効な小テストの除外、学生のアクセス拒否を確認する。
- 最初のCIでPHPの改行規約違反を検出して修正。「一般」が単元一覧に出る問題も型を正規化して修正。

## 残る課題

この段階は入口の支援であり、教材づくりの完成形ではない。標準フォームの設定量、小テスト保存後の問題追加、活動保存後にコースへ戻って作成支援を再開する一往復は残る。

実際の教師による説明書なしの試行とTopicsとの比較は未実施。操作時間短縮や「迷わない」という効果はまだ主張しない。新しい画面の小画面・キーボード操作の専用検査も別途必要。

次の評価では「説明を置く→練習問題とフィードバックを作る→必要な提出先を用意する」を一単元で最後まで行い、標準フォームのどこで支援が必要かを特定する。独自設定を増やす前に、その場の説明や戻り先の改善で解消できるかを検討する。
