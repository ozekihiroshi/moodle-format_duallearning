# Python 1.1試行のフィードバック対応

対象: https://github.com/ozekihiroshi/moodle-format_duallearning/issues/1

## 対応した範囲

- 単元の作成支援に「Markdown教材を加える」を追加。LessonMarkが有効で追加権限がある場合のみ表示し、標準作成フォームへ進む。必須依存にはしない。
- コース内で閲覧可能な課題がない場合、提出欄の見出し・説明も表示しない。単元単位の判定ではなく、既存のコース概要の範囲を維持する。
- 手動の完了マークは、コード実行成功・理解・提出・採点を意味しないと日英で明示。
- 活動名と本文先頭のH1が重複する件は、折り畳まれた作成ヒントに追記。既存原稿を自動変換しない。
- 回帰テストで発見した、提出記録のない学生の課題表示時の型エラーも修正。

## 確認

- ローカルの教師画面（コース32、単元295）からLessonMarkの作成フォーム、Markdown入力欄、作成支援への戻りリンクを確認。保存せずキャンセルした。
- 課題なし・非表示課題のみ・閲覧可能な課題ありを学生として比較する自動テストを追加。
- LessonMarkがインストールされている環境でも既存の作成支援テストを実行できるようにした。

## 今回含めない範囲

- Lab LTIは環境固有の設定が必要。配布用バックアップから除外し、導入先で接続を設定する運用を維持する。
- Python教材の原稿およびコース内容は変更しない。修正後の実教材での使いやすさは次の試行で評価する。
- 公開済みalpha2のタグやZIPは差し替えない。
