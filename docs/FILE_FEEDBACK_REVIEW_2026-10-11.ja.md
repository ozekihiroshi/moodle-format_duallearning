# 返却ファイルの検証 — 2026年10月11日

[English](FILE_FEEDBACK_REVIEW_2026-10-11.md)

返却ファイルへの導線が不足しています。公開後の標準課題画面にはファイルが表示されましたが、Dual Learningの概要は「提出済み」のままで、結果を確認する操作が出ませんでした。開発者による比較検証であり、初見利用者の使いやすさや学習効果を実証したものではありません。

## 環境と方法

隔離したlocalhost:8098で、Moodle 5.2.4（Build 20261005）、PHP 8.3.33、Boostを使用しました。製品コードはa1abd21、文書を含むHEADは81f4157です。コース22はDual LearningのSelf paced、23はTopics、課題モジュールは63と66です。既存の検証データは保持しました。

両課題ともオンラインテキスト提出、評点なし、採点ワークフロー有効、最大2試行、提出のみを条件とした自動完了です。返却ファイルを有効にし、コメント機能は有効ですが本文は空にしました。「返却内容がファイルだけ」の検証であり、コメント機能が無効の構成とは区別します。架空の学生comparisonstudentでChromeから確認しました。

提出・採点レコード・公開状態・ファイルは、標準APIとファイルストレージ、DB操作による検証スクリプトで準備しました。学生の提出フォームや教師のアップロード・公開フォームを通した検証ではありません。初回の返却ファイルはattempt-1-feedback.txt、本文は「Attempt 1 feedback: Include the unit C.」です。公開後、新しいフィードバックのない2回目の提出状態を用意しました。

## 改善点と次の対応

**F1：概要がファイルだけの返却を検出していない。** 現在、評点なし課題の返却判定はコメントだけが対象です。標準プラグインのis_emptyと既存の公開判定を使い、有効・表示可能な今回の返却ファイルも判定対象にします。コメントとファイルが共存する場合も含め、「今回のフィードバックを確認」という操作から標準課題画面へ案内する方針です。概要にファイル名・内容・直接ダウンロードURLは転載しません。

回帰検証では、公開前後、空または無効なプラグイン、コメントとの併用、前回だけファイルがある再提出を扱います。既存の評点付き課題の判定を維持し、両学習モードを確認します。今回の監査ではまだ改修していません。

**F2：標準画面が過去の評点なしフィードバックを表示しない。** Moodle 5.2.4の両フォーマットで、既存のコメント履歴と同様の制限を再現しました。COMMENTS_ONLY_REVIEW_2026-10-11.ja.mdに続くMoodle側の観察事項として記録します。コア改変やフォーマット独自の履歴表示は行いません。

**F3：コメント機能を無効にした構成は別途調査が必要。** 最初の評点なし・返却ファイル有効・コメント無効の検証データでは、標準課題画面に「Cannot load the grade item」が出ました。空のコメント機能を有効にし、評定項目を更新すると表示できました。確認した標準実装では、評定表へ返すプラグインが有効ならテキスト評定項目を作ります。ただしスクリプトで準備したデータなので、教師が通常のフォームで設定した場合まで確認したものではありません。フォーマットの不具合とは断定せず、外部への報告も行いません。

## F1の改修と回帰検証 — 2026年10月11日

907e6b9で実装しました。個人提出・評点なしの課題では、公開判定を通過した今回の試行について、標準の返却ファイルプラグインを確認します。ファイルがあれば「提出済み・フィードバック返却済み」と「今回のフィードバックを確認」を表示します。コメントとファイルを併用する場合も同じ操作で案内します。コメントだけの場合と評点付き課題の既存動作は維持しています。日英の文言を追加しました。

自動回帰テストはSelf pacedとTeacher guidedの両方を対象とします。提出・採点レコードがない場合の読み取りによる不要な作成、空の返却、採点中・公開準備・公開済み、ファイル機能無効、コメントだけへの切り替え、併用、コメント機能無効、下書き・再提出要求、新しい返却がない再提出、新しい試行への返却、ワークフロー無効、評点付き課題の既存判定、教師への非表示を確認します。生成HTMLにファイル名・本文・直接ダウンロードURLを含めず、標準課題画面へリンクすることも対象です。

同じMoodle 5.2.4の隔離環境で、実際の学生アカウントから確認しました。前回分だけがある段階では結果確認の操作は出ません。今回の試行1（採点ID 11）に2回目のファイルを用意し、採点中は操作も標準画面のファイルも非表示でした。公開後は新しい操作をクリックすると、標準画面にattempt-2-feedback.txtが表示されました。今回のコメントを追加しても同じ操作が維持され、コメントとファイルの両方へ到達しました。学生側はブラウザ操作、教師のアップロード・公開相当の準備は検証スクリプトです。Topics側には新たな返却を追加していません。

コアの履歴表示とコメント機能無効時の初期検証データの問題は、上記の記録を維持します。今回の改修対象ではありません。アップロードからダウンロードまでの一巡、モバイル、支援技術、第三者による評価は引き続き対象外です。
