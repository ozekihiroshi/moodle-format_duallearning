# 教材作成・学生ロール確認の回帰検証 — 2026年10月11日

修正候補で教材作成から確認・修正への一巡を検証した。開発者による回帰検証であり、初見の教師の観察や学習効果の実証ではない。

## ブラウザー確認

隔離環境のMoodle 5.2.2、PHP 8.3、Boost、修正候補のコースフォーマットを使用。教師と学生は別アカウント。元の比較コース2〜5は編集していない。

| 確認 | 結果 |
| --- | --- |
| 既存の非公開ユニットをContinueから選択 | コース8・セクション14の編集を再開 |
| 学生ロールで確認 | 非公開ユニットとPageは非表示。確認の限界と戻るボタンを表示 |
| 教師へ戻る | 同じユニットと教材編集へのリンクに復帰 |
| 編集・保存 | 教材名を変更・保存・表示した後、元の名前に復元。本文は維持 |
| 空コースから作成 | 新規の検証用コース11に非公開ユニット20を作成 |
| 説明教材を追加 | Page 12に本文を保存。戻るリンクはユニット20へ接続 |
| 学生ロール確認→戻る→修正 | 非公開を維持。教材名を修正・保存し、同じユニットへ復帰 |
| 独立した学生アカウント | 非公開下書きも教師用の復帰操作も表示されない |
| 学生でPage URLを直接開く | Moodleが非公開教材へのアクセスを拒否 |

コース11は非公開の検証用データとして残す。教材名は「Regression explanation — revised」、本文は「Read the table headings and identify the temperature unit.」。自動操作では標準エディターのソースコード入力を使用したため、初見の教師が迷わず入力できることの確認とは区別する。

## 自動検証

CIはPHP 8.3／8.4の構文・Moodle規約・PHPDoc・プラグイン検証・savepoints・PHPUnitを実施する。PHP 8.3ではプラグインのBehat全シナリオと、時刻を固定した学生ロール切替のキャッシュ回帰検証も実施する。JavaScriptのビルド・lintと、再現可能なZIPへの生成済み概要JavaScriptの同梱検査を追加した。

Fragmentの追加テストは、コンテキスト不一致、未参加ユーザー、利用者IDの指定による非公開教材取得を検証する。完了・取り消しのBehatは両モードで再読み込みなしの更新を確認する。

初回CIでPHPコメントの小文字始まりと、build/除外設定がamd/buildまで除外する問題が見つかった。コメントを修正し、除外を/build/に限定した。生成済みファイルをGitに含め、Moodleのビルド結果との一致を確認する。今回の検証ではバージョン更新、本番反映、Marketplace公開は行わない。
