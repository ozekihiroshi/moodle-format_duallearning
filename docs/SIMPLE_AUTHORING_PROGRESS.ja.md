# シンプルな作成支援：初回改修記録

2026-09-18。開発ブランチ `codex/simple-authoring`。申請済みalpha1のZIP・バージョンは変更しない。

## 実装した範囲

- 編集モードのコース全体画面に「ひな型から単元を作る」を追加。
- 現在のコース方式に合う日英の本文ひな型。予習、理解確認、質問、復習を両方式に含める。
- 入力は単元名と学生向け本文。初回から本文があり、自由に書き換え・削除できる。
- 標準セクションとして末尾に非表示で作成。独自テーブル・設計項目・個人の進捗記録は追加しない。
- サーバー側でコース形式、コース更新権限、セクション表示権限を検証。フォームはMoodle標準のPOST・sesskey検証を利用。

この段階では、画像添付は下書き作成後の標準編集から行う。ひな型画面はテキスト編集を先行し、活動の自動作成・再配置・コース方式変更は行わない。学校給食のデータ確認を例とする文章は教科に合わせて書き換える必要がある。

| 日英 | 両言語・両方式でひな型の本文キーが存在することを確認。画面の言語切替試験ではない |

実機試験は新規クラスを一時パスから読み込み、既存のコース画面のプラグインファイルは差し替えていない。localhostの通常画面にはまだ新しい入口は出ない。試験スクリプトは作業環境 `LessonMark/output/verify-unit-starter.php` と `check-unit-starter.sh` にある。

## 次に行うこと

隔離したCI環境でPHPUnit・PHPDocを実行し、ローカル画面へ適用して、作成→取消／保存→標準編集→公開の操作を確認する。学生非表示・教師権限・日英・キーボード・小画面を確認し、標準セクションのバックアップ復元も試験する。

その後、作成者の操作観察に基づいて活動追加支援を設計する。今回の動作試験を「説明書なしで誰でも作れる」「Topicsより簡単」の証拠とはしない。
