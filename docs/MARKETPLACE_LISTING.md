# Moodle Marketplace listing

## Name

Dual Learning

## Component

`format_duallearning`

## Short description

Switch one Moodle course between self-paced and teacher-guided overviews while keeping standard activities, completion, submissions, grades, and deadlines unchanged.

## Description

Dual Learning adds an overview above Moodle's standard Topics course layout. In self-paced mode, learners see their next visible incomplete activity, work links, and assignment state. In teacher-guided mode, the same course also highlights visible question forums for the current class workflow.

Teachers select the mode in the normal course settings. The switch changes presentation only: Moodle remains the source of truth for access restrictions, completion, submission, grading, extensions, and calendar dates. The format can therefore move from a guided class to later self-paced review without replacing the course or its learning history.

The plugin includes English and Japanese strings, stores no additional personal data, inherits the standard Topics format, and works independently of the Dual Learning theme.

## Requirements and limitations

- Moodle 5.2.
- The standard Topics course format.
- Group submission details and individual deadline overrides remain on Moodle's standard assignment page.
- A mode change does not automatically rewrite course instructions, deadlines, or forums.
